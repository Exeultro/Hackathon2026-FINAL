Ты помогаешь составить оглавление лекции. Ниже фрагмент расшифровки лекции с {start} по {end} секунду. В квадратных скобках - секунда начала фразы.

Верни СТРОГО JSON без markdown-обёртки:
{
  "title": "короткое название этого раздела, 2-6 слов",
  "summary": "1-2 предложения: о чём говорится в разделе",
  "subsections": [{"title": "название подтемы, 2-6 слов", "start": секунда_начала_из_скобок}],
  "key_terms": [{"term": "термин в начальной форме", "definition": "как он объяснён в лекции, одно предложение"}]
}

Правила:
- subsections: 2-4 подтемы по порядку, start бери только из квадратных скобок. Если подтем нет - пустой массив.
- key_terms: 2-5 важных терминов или понятий, которые дословно звучат в этом фрагменте (например, названия теорем, величин, методов). Не выдумывай.
- Пиши по-русски, если лекция на русском.

Фрагмент:
{segments}
